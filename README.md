# 🌍 TravelDestinations
A beautifully crafted demo app built with **SwiftUI** that showcases modern iOS development practices including layout optimization, real-time data fetching with Firestore, and a clean MVVM structure.

---

## 🎯 Overview
**TravelDestinations** is a SwiftUI-based application that displays a dynamic collection of travel locations using data fetched live from **Firebase Firestore**. Users can toggle between a list or grid view, explore map locations, and watch embedded travel videos.

This project was built to demonstrate:
- Clean UI with responsive layout using SwiftUI
- Real-time data handling with Firebase Firestore
- Modular and maintainable architecture using MVC
- Code reusability through Swift Generics
- Native framework integration (MapKit, AVKit)

---

## 🛠️ Features
- 🧭 **Tab-based navigation** using `TabView`
- 🌐 **Live data fetching** from **Firebase Firestore**
- 🧩 **Grid & List toggle** using `LazyVGrid` and `LazyVStack`
- 🗺️ **Map view** integration via `MapKit`
- 🎞️ **Video playback** using SwiftUI’s AVKit integration
- ♻️ **Reusable components** using **Generics**
- ⚡️ **Optimized layout** with computed properties

## 🚀 Getting Started

To run the project locally:

1. Clone the repository  
   `git clone https://github.com/Developer-Zohaib/TravelDestinations.git`
2. Open the `.xcodeproj` in **Xcode 15+**
3. Make sure you have a working Firebase setup and your own `GoogleService-Info.plist`
4. Select a simulator and hit **Run** ▶️
